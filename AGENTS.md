# WealthTracker UI preference

- Default every new feature and screen to a compact, information-dense layout. This is an explicit user preference, not limited to the technical strategy screen.
- Keep key values and status visible; put long explanations and reference material behind clearly labeled disclosures instead of permanently expanded blocks.
- Use concise labels, restrained card padding and vertical spacing, and avoid oversized empty areas. Preserve legible text and practical touch targets (about 44 pt for primary interactions).
- When updating existing screens, maintain this compact visual language unless the user explicitly requests a different layout.
